# Lab 7.0 – Transfer Learning Image Classifier (Cats vs Dogs)

Streamlit app using the best of three transfer learning models (MobileNetV2, ResNet50, EfficientNetB0).
Best model: **EfficientNetB0** (pre-trained on ImageNet). Upload an image to get a cat/dog prediction.

The trained model (`best_model.keras`) is downloaded from Google Drive on first start.
